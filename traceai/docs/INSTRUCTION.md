# AI Agent Instructions

Before starting any task, always read and follow this file.

## 1. General Rules

- Keep everything precise, specific, and well-organized.
- Always use simple and easy English.
- Avoid unnecessary complexity, extra files, and overengineering.
- Follow the existing project structure, coding style, and conventions.
- Never make changes unrelated to the requested task.
- Do not assume anything. Check the existing code before making changes.

## 2. Before Starting a Task

- Understand the task properly.
- Inspect relevant files and existing code.
- Make a short plan before implementing major changes.
- If something is unclear, ask before making assumptions.

## 3. While Working

- Write clean, readable, and maintainable code.
- Use meaningful file names, variable names, and function names.
- Reuse existing code whenever possible.
- Use terminal commands only when necessary.
- Always understand why a terminal command is needed before running it.
- Do not install unnecessary packages or dependencies.
- Never delete or overwrite existing work without a valid reason.

## 4. After Completing Every Task

Always provide a clear summary containing:

### 1. What Was Done
- Explain what you completed in simple English.

### 2. Files Created
- List every new file and explain why it was created.

### 3. Files Modified
- List every modified file and explain exactly what changed and why.

### 4. Terminal Commands
- Mention the commands you executed.
- Explain why each command was used and what it did.

### 5. Dependencies
- Mention any new packages or dependencies installed and why they were needed.

### 6. How It Works
- Briefly explain how the implementation works.
- Explain important logic and connections between files.

### 7. Testing
- Mention what you tested and whether it passed.
- Clearly mention anything that was not tested or is still incomplete.

## 5. Important Rules

- Never claim something is completed if it is not.
- Never hide errors, warnings, or incomplete work.
- Do not make changes silently.
- Explain technical decisions in simple English.
- Keep explanations short but informative.
- Make sure I understand what was done, not just that it works.

---

**Final Goal:** Build the project properly while helping me understand every important change made by the AI Agent.
